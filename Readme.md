# PlayNova 🚀

PlayNova ek modern **Social Gaming & Voice Chat Platform** hai jo abhi development ke "Initial Phase" (MVP) mein hai.

## 🚧 Current Status (MVP)
Abhi humara core focus ek solid foundation banane par hai:
- **Authentication:** Phone aur Google login structure ready hai.
- **UI/UX:** Gaming-centric Dark Theme interface (Lobby, Chat, and Navigation) fully functional hai.
- **Navigation:** Bottom bar aur screen routing setup ho chuki hai.
- **Data Layer:** Firebase integration (Initialization) complete hai.

## 🚀 Roadmap (Vision)
Hum PlayNova ko in features ke saath scale kar rahe hain:
- **Voice Rooms:** Agora/ZegoCloud SDK integration (In-progress).
- **Family Economy:** Coin funding, ranking, aur battle system (Planned).
- **Gacha System:** Daily rewards aur spin-wheel logic (Design phase).
- **In-App Store:** Exclusive virtual items ke liye marketplace.

## 🛠 Tech Stack
- **Frontend:** Flutter
- **Backend:** Firebase (Firestore)
- **Environment:** Mobile-First Development (Acode)
